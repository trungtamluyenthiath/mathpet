# MathPet Adventure — bản chơi thử

Nhánh `gh-pages` chứa bản website đã build, không phải mã nguồn phát triển.

Trong GitHub chọn Settings → Pages → Deploy from a branch → gh-pages → / (root) → Save. Chỉ coi website đã hoạt động sau khi mở và kiểm tra địa chỉ Pages thực tế.

Tệp MathPet-Adventure-choi-thu.zip chứa bản HTML tự chứa, hướng dẫn và giấy phép. Nội dung học tập đang chờ giáo viên duyệt. Để thử toàn bộ chiến dịch, bật xem thử chưa duyệt trong Ba thế giới → Khu biên soạn và duyệt nội dung.

Đồ họa và âm thanh do dự án tạo; giấy phép thư viện và font trong thư mục licenses. Không thu thập định danh học sinh.
